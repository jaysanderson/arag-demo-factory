What shipped

The headline · new architecture

The factory became a palette, not a template kit

The portal is no longer a fixed shell toggling prebuilt panels. It's a palette the SE paints with: grounded pigments (hooks like useAsk, useSearch, useGraph), a design medium (Hero, Section, TileGrid on the demo's own colours), and a composition seam to paint a bespoke home + pages. Crucially, the guarantees live in the materials: <GroundedAnswer> can't render an uncited claim, <CitedMetric> can't render a number without KB provenance, and a build-time lint rejects hardcoded metrics and external fetches. Free composition, incorruptible materials.

Quality bar

A mandatory bar, set from the live portfolio

Walked ~20 deployed ARAG apps end-to-end — Atlas, Meridian Codex, Document Intelligence Studio, Research Portal, Ironbark, Racing WA and more. The bar: a real application (app shell, live status, auth where it fits), the whole ARAG product woven in, and bespoke design craft — never four disconnected tiles or a component dump.

Signature surface

“Journey through the context” — now built in

Below any cited answer, a cinematic, auto-playing walk through the grounding: strongest match first, each source with an animated confidence ring, classification chips, a cited-in-the-answer badge, the supporting passage, and a live, resource-scoped “how does this relate?” answer — with narration and a replayable trail. Proof that an answer is grounded, not generated. Typechecks and builds clean.

Creative mandate

Creativity is now the critical rule

“We provide the colours; the package is the artist.” Every build must be a bespoke, believable product with its own identity — never a recoloured template or “random React everywhere.” Baked into the session hook, AGENTS.md, CLAUDE.md, and the Copilot instructions.

Inspiration, not replicas

Blueprints became cues, not a catalogue

The reference library is a source of ideas — never a menu, never copied. The factory now invents a fresh, realistic use case per prompt: a new fictional company that merely rhymes with the exemplars. Every document, number and name is believable — synthetic, never fake.

Provisioning · verified live

NUA-key auto-provisioning

Hand the factory a NUA key and it creates and manages its own ARAG assets with no setup by hand. Proven end-to-end against a real account: create → mint token → ingest → cited answers, one credential, zero manual steps. The exact regional recipe is pinned into create-kb.mjs.
