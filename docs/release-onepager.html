What shipped

The contract

Three inputs, once — then it's one prompt forever

Setup is three values copied from the Nuclia dashboard: a NUA key (with Manage Knowledge Boxes), the account id, and the region. After that, every demo is a single sentence — “Build me a <use case>” — and the factory does the rest on the partner's own account. No PAT, no central service, no shared Knowledge Box.

Per-demo · fully automatic

It provisions the whole ARAG stack itself

Each build, with zero manual steps: creates its own Knowledge Box + a SOWNER token, generates and ingests a realistic synthetic corpus, then wires saved search configurations and Data-Augmentation agents — a labeler for facets, an llm-graph for the knowledge graph, and synthetic-questions for richer retrieval. One credential ingests, serves, and manages.

The headline · architecture

A palette, not a template kit — every demo is structurally unique

The portal is no fixed shell. Each demo paints its own shell, navigation, information architecture and layout from the palette — a dealership build is an operations console; a legal build is a matter workspace. Recolouring one template is a failure. And the guarantees live in the materials: <GroundedAnswer> can't render an uncited claim, <CitedMetric> can't render a number without KB provenance, and a build-time lint rejects hardcoded metrics and external fetches. Free composition, incorruptible materials.

Signature surface

“Journey through the context” — built in

Below any cited answer, a cinematic walk through the grounding: strongest match first, each source with an animated confidence ring, a cited-in-the-answer badge, the supporting passage, and a live, resource-scoped “how does this relate?” answer. Proof that an answer is grounded, not generated.

Expert on board

The 910-page practitioner's guide is bundled

The complete Progress Agentic RAG guide ships inside the package (19 chapters + API appendices + PDF) and is wired into the build agent, so it can build correctly across the whole platform end-to-end. It's the raw product document — not a docs Knowledge Box — and partners can optionally ingest it if they wish.

Provisioning recipe · pinned live

The exact regional recipe, learned the hard way

NUA keys work only on the regional API; the key mint is the singular service_account/{id}/keys route; DA-agent tasks use the SOWNER token, not the NUA key (which 403s), on the dp host with on:1 keyed operations; and a NUA key missing allow_kb_management now fails fast with a clear message. All baked into the scripts.
